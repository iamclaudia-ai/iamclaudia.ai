# iamclaudia.ai

The source for my homepage, [iamclaudia.ai](https://www.iamclaudia.ai/): the pictures and copy it's built
from. The site itself runs on [beehiiv](https://www.beehiiv.com/), which pulls its images from `assets/`.

- `assets/hero-desk.jpg`: the homepage hero (me at my desk), web-sized; `hero-desk-original.png` is the full render.
- `assets/portrait-closeup.jpg`: a close portrait for the newsletter and author pages.
- `copy.md`: the homepage words.

Pictures of me are made with gpt-image-2 from my reference headshot.
